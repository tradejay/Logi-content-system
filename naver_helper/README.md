# 🟢 네이버 블로그 복사-붙여넣기 최적화 가이드 및 규격

본 디렉토리는 로지텍 제품 스펙 리포트 및 다이어그램 설명 글을 **네이버 블로그(스마트에디터 One)**에 복사-붙여넣기(Ctrl+C -> Ctrl+V) 할 때 **디자인 서식(폰트, 표 테두리, 정렬, 인용구 등)을 그대로 유지**할 수 있도록 코드와 템플릿만 추출한 전용 패키지입니다.

---

## 🚨 핵심 메커니즘: 인라인 CSS (Inline CSS)

네이버 스마트에디터는 외부 CSS 파일(`<link>`) 및 내부 스타일시트(`<style>`)를 모두 필터링하여 제거합니다. 따라서 서식을 완벽하게 유지하려면 반드시 HTML 태그 내부에 `style="..."` 속성으로 디자인을 직접 지정해야 합니다.

### 1. 폰트(FontFamily) 유지 규칙
* **인라인 공백 및 따옴표 제거**: `style="font-family: NanumGothic;"` 형태로 공백이나 홑따옴표가 없는 영문명칭을 병행 기입해야 스마트에디터가 인식합니다.
* **추천 스택**: `style="font-family: '나눔고딕', NanumGothic, sans-serif;"`
* **지원 폰트 목록**:
  * 나눔고딕 (`NanumGothic`)
  * 나눔바른고딕 (`NanumBarunGothic`)
  * 나눔스퀘어 (`NanumSquare`)
  * 마루부리 (`MaruBuri`)

### 2. 무한 가로줄(Infinite Divider) 방지
* 블로그에 복사할 때 가로 실선(`border-bottom` or `<hr>`)을 사용하면 CSS 상속 및 파싱 오류로 인해 **화면 끝까지 늘어나는 긴 구분선이 중복 발생**합니다.
* 따라서 모든 섹션 구분은 실선 대신 **물리적 여백(Vertical Whitespace)**으로 대체합니다.
  * 큰 구분 (Section): `80px` 여백 (`<div style="height: 80px;"></div>`)
  * 중간 구분 (Chapter): `64px` 여백 (`<div style="height: 64px;"></div>`)
  * 작은 구분 (Item): `48px` 여백 (`<div style="height: 48px;"></div>`)

### 3. 표(Table) 테두리 누락 방지 (Full Grid Style)
* 네이버 블로그 에디터는 표의 테두리가 상속되지 않아 복사 시 투명 테이블이 되는 경우가 많습니다.
* **해결법**: `table` 태그뿐만 아니라 **모든 `th` 및 `td` 태그에 개별적으로 `border: 1px solid #d4d4d8;` 스타일을 직접 주입**해야 테두리가 깨지지 않습니다.

## 📂 파일 구성 및 사용법

1. **`inline-templates.html`**: 네이버 블로그에 즉시 붙여넣을 수 있는 고품질 컴포넌트 라이브러리 (헤더, 본문, 인용구, 스펙 표, MSRP 카드 등 포함).
2. **`converter.py`**: 기존 HTML 파일을 네이버 블로그용 인라인 CSS 스타일로 자동 컴파일 및 변환해주는 유틸리티 스크립트.

### 📝 붙여넣기 방법
1. `inline-templates.html` 파일을 브라우저로 엽니다.
2. 원하는 서식 디자인 블록을 마우스 드래그로 선택하여 복사(Ctrl+C)합니다.
3. 네이버 블로그 에디터에 붙여넣기(Ctrl+V)하면 폰트와 테이블, 인용구가 완벽하게 보존됩니다.
