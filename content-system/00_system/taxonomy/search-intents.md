# 검색 의도 분류 체계 (search-intents.md)

네이버 검색 사용자의 검색 질의(Query)에 내포된 목적(Intent)을 정밀하게 분류하여 콘텐츠 방향을 결정합니다.

---

## 1. Problem Solving (문제 해결형)
- **사용자 심리**: 현재 발생한 기술적 장애나 불편함을 즉시 해결하고 싶음
- **주요 키워드 패턴**: "~ 끊김", "~ 울림", "~ 연결 안됨", "~ 소리 안남", "~ 해결법"
- **콘텐츠 전략**: 빠른 조치 팁(Quick Fix)을 상단에 제공하고, 근본적 하드웨어 해결책으로 유도

## 2. Concept Understanding (개념 및 원리 이해형)
- **사용자 심리**: 새로운 기술 용어나 장비의 작동 방식을 명확히 알고 싶음
- **주요 키워드 패턴**: "화자추적 카메라 원리", "PTZ 카메라 뜻", "AEC 에코캔슬링이란"
- **콘텐츠 전략**: 기술 구조도 및 다이어그램을 활용하여 비전공자도 이해하기 쉬운 비유와 전문 지식 결합

## 3. Configuration (설정 및 구축형)
- **사용자 심리**: 이미 장비나 플랫폼을 보유하고 있으며, 최적의 세팅을 완료하고 싶음
- **주요 키워드 패턴**: "Zoom Rooms 회의실 세팅", "로지텍 랠리바 설정", "마이크포드 연결법"
- **콘텐츠 전략**: 스크린샷 가이드, 메뉴 경로(Path) 안내, 케이블 결선도 중심 작성

## 4. Comparison (비교 분석형)
- **사용자 심리**: 예산이나 룸 크기에 따라 어떤 제품이 유리한지 저울질하고 있음
- **주요 키워드 패턴**: "MeetUp 2 vs Rally Bar", "회의실 화상 카메라 비교", "올인원 바 vs 분리형"
- **콘텐츠 전략**: 스펙 비교표, 룸 크기별 권장 매트릭스, 장단점의 투명한 공개

## 5. Evaluation (제품 검토 및 구매 결정형)
- **사용자 심리**: 특정 모델 도입을 최종 검토 중이며, 실사용 후기와 스펙상 제약을 알고 싶음
- **주요 키워드 패턴**: "로지텍 랠리바 실사용 후기", "밋업2 스펙", "화상회의 장비 견적"
- **콘텐츠 전략**: 실사용 시나리오, 공간별 필수 고려사항, 전문 컨설팅 상담(CTA) 연계
