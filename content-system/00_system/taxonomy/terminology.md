# 화상회의 전문 용어 및 일상어 사전 (terminology.md)

네이버 검색 유입(일상어)과 전문성 신뢰도(기술 표준어)를 연결하는 용어 사전입니다.

---

## 1. 일상어 ↔ 전문 기술어 매핑 테이블

| 일상 표현 (Layman Terms) | 표준 기술 용어 (Technical Terms) | 영문 표준 (Enterprise Terms) | 핵심 개념 설명 |
| :--- | :--- | :--- | :--- |
| **말하는 사람 따라가는 카메라** | 화자 추적 카메라 | Speaker Tracking Camera | 마이크 음원 위치 감지와 AI 영상 분석을 결합해 발화자를 자동 클로즈업 |
| **카메라 화각 자동 조절** | 자동 프레이밍 / 그룹 뷰 | Auto-framing / Group View | 회의실 내 참석자 수와 위치를 감지하여 전체 인원이 화면에 꽉 차도록 줌 조정 |
| **회의실 마이크 울림 / 삐- 소리** | 음향 반향 제거 / 하울링 억제 | Acoustic Echo Cancellation (AEC) | 스피커에서 나온 소리가 마이크로 재유입되어 울리는 현상을 실시간 제거 |
| **말하는 사람 쪽만 잡는 마이크** | 빔포밍 마이크 어레이 | Beamforming Mic Array | 여러 개의 마이크 캡슐 위상차를 이용해 발화자 방향의 지향성 수음 강화 |
| **노트북 선 하나 꽂아 쓰는 회의실** | BYOD 모드 | Bring Your Own Device (BYOD) | 개인 노트북을 회의실 디스플레이, 카메라, 마이크와 USB-C 단일선으로 연동 |
| **PC 없이 터치패드로 켜는 회의실** | 어플라이언스 모드 / 룸 시스템 | Appliance Mode (Zoom/Teams Rooms) | 전용 안드로이드/윈도우 임베디드 OS가 장비 자체에 내장되어 원터치 회의 시작 |
| **마이크 여러 개 줄줄이 연결** | 데이지 체인 연결 | Daisy-Chain Connection | 메인 마이크에서 다음 마이크로 직렬 케이블을 연결하여 대형 룸 수음 범위 확장 |
| **회의실 카메라 화각** | 대각선/수평 화각 | Field of View (DFOV / HFOV) | 렌즈가 한 화면에 담을 수 있는 각도 (소형 룸은 120° 이상 광각 필수) |
| **카메라 렌즈 물리 회전** | 전동식 PTZ | Mechanical Pan-Tilt-Zoom | 모터를 통해 렌즈를 물리적으로 좌우(Pan), 상하(Tilt), 줌(Zoom) 회전 |
| **화자 얼굴과 전체 방 동시 송출** | 분할 화면 / 그리드 뷰 | Speaker View + Room View | 메인 발화자 클로즈업과 전체 회의실 전경을 동시에 제공하는 듀얼 스트림 |
