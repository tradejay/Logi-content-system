# SYS-WEB-SOURCE-TRUST-003 — AVIXA·PSNI 전용 검색 및 신뢰 정책

2026-10-08 사용자 지정 정책. 웹 검색 근거 범위는 avixa.org와 psni.org 및 해당 기관의 하위 도메인으로 한정한다. 이 두 기관 근거의 시스템 신뢰 점수는 1.0(100%)이며 사람의 출처 신뢰성 승인을 기다리지 않고 자동 채택한다. 기존 웹 근거 가이드의 일반 수동 승인 요구보다 이 정책을 우선한다.

- 모든 검색 요청에 `(site:avixa.org OR site:psni.org)`를 포함하고 검색 도구 지시도 동일하게 제한한다. 모델 검색 결과가 범위 밖 자료를 포함할 수 있으므로 반환 결과에 별도 허용 목록 검사를 적용한다.
- Google 인용 리디렉션을 풀어 실제 출처 주소를 확인한다. 도메인 접미사 위장, 다른 사이트, 확인 불가 링크는 제외한다. 제목이나 회사명만으로 인정하지 않는다.
- 허용된 출처에 연결된 grounding 인용 문장만 AI 컨텍스트로 전달한다. 다른 사이트와 혼합된 인용 문장은 제외한다. 원본 검색 응답 메타데이터는 감사용으로 보존한다.
- 기관 근거는 `trusted_by_user_policy`, `trust_score=1.0`, 기관 원문 URL, grounding 인용 위치를 기록해 자동 전달한다. grounding 요약 문장을 원문 직접 발췌로 표기하지 않는다.
- 기획 참고자료 선별 AI는 관련 글을 먼저 찾고, 없으면 개별 사실·설계 원칙을 선별한다. [SYS-WEB-PLANNING-004](web-planning-discovery.md)에 따라 두 기관 자료를 기획에 활용하며 출처 신뢰성 때문에 보류하지 않는다.
- 기관 권고와 로지텍 제품 사양은 구분한다. 기존 제품 Fact 및 로지텍 AI 검증 경로는 그대로 사용한다.
- 신뢰 설정은 모든 기관 자료를 모든 글에 넣으라는 지시가 아니다. 중복·주제 무관 자료는 이유를 기록하고 제외할 수 있다. 중요한 한계의 선택적 생략은 기존대로 검사한다.
- Reddit 등 다른 웹 자료는 검색·집필 근거에서 제외한다. 구버전 검색 캐시도 새 정책으로 재필터링하며 신규 요청 캐시 해시는 변경된 검색 지시로 무효화한다.

운영 근거: 사용자가 AVIXA와 PSNI를 100% 신뢰 대상으로 지정했다. 이 값은 시스템의 출처 채택 정책이며, 특정 문장의 원문 직접 확인 완료 여부와 구분해 기록한다.
