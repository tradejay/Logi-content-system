# SYS-POSTPROCESS-006 — 키 전환·이미지 제작·발행 전 점검

Version: 1.0.0 / 2026-10-08

등록된 Gemini 키는 순서대로 한 번씩 사용한다. 환경변수 키가 있으면 해당 명시적 설정을 우선한다. HTTP 401/402/403/429/500/502/503/504에 한해 다음 등록 키를 시도한다. 입력과 규칙·출력 계약은 유지하고 선택된 키에서도 입력 토큰을 실측해 한도 초과를 차단한다. 안전 차단·출력 잘림·규칙 수신 실패·원고 계약 오류를 키 전환으로 우회하지 않는다. 키 값은 로그에 남기지 않고 key_slot, key_tier와 실패 상태만 기록한다. 2026-10-08 사용자 확인에 따라 현재 등록 순서의 요금제 구분은 paid/free/free/free이며 config/config.json의 gemini_api_key_tiers에 저장한다. 이는 사용자 확인값이며 API로 결제 상태를 조회한 결과는 아니다. 명시적 환경변수 키 또는 별도 이미지 키는 구분 미확인으로 기록한다. 여러 키가 같은 프로젝트라면 한도도 공유할 수 있으며 등록 키가 있다는 이유로 무료라고 표시하지 않는다.

집필·자체 검토·로지텍 검토를 통과한 원고에서 이미지 요구 위치를 확인한다. 기존 공식 사진·GIF·공통 배너를 우선하며, 확보가 필요한 공식 제품 자료를 생성 이미지로 대체하지 않는다. generation_request는 마지막 원고의 문맥과 핵심을 기준으로 생성한다. 이전 기획 프롬프트의 삭제된 수치를 그대로 재사용하지 않는다. GUIDE-04-IMAGES와 RULE-ASSET-TRUTH의 활성 본문·해시를 전달한다.

생성 파일은 실제 이미지 형식·크기·해시를 확인한 뒤 글별 asset registry에 candidate로 등록한다. 파일 생성은 승인과 다르다. 검토자·출처·권리·문구·제품 주장·공개 URL을 확인하기 전에는 approved로 바꾸지 않는다. 이미지 출력에서는 텍스트 모델처럼 규칙 ID 수신을 기계적으로 확인하지 못하므로, 전달 로그와 사람의 시각 검토를 구분해 기록한다. 생성 실패는 미해결로 남기며 후보를 다른 글에 자동 배포하지 않는다. 업로드 자산도 같은 후보 검토를 거친다.

원고가 있는 실행에는 발행 전 콘텐츠 검사를 저장한다. 검사에는 제목의 주제 표현·검색어 반복, 긴 문단 중복, 내부 라벨 잔존, 읽기 편한 구분, 미승인 이미지 등이 포함된다. 정량 임계값은 내부 검토용이며 네이버의 공식 순위 산식으로 취급하지 않는다. 결과는 원고 hash와 연결하고 자동으로 원고를 고치거나 발행하지 않는다. 네이버 지수·순위·색인 여부를 이 검사로 추정하거나 보장하지 않는다.

구현 설정: config/pipeline-postprocess.json. 발행 전 검사 참고: [네이버 콘텐츠 작성 권장 사항](https://searchadvisor.naver.com/guide/content-basic), [콘텐츠 스팸 사례](https://searchadvisor.naver.com/guide/content-abusing). 이는 공개 콘텐츠 품질 지침이며 블로그 내부 지수 산식을 제공하는 자료가 아니다.

2026-10-12 실행 설정: `gemini_key_policy=free_only`이면 사용자 지정 무료 슬롯 2·3·4만 순서대로 시도한다. 유료 키와 요금제 미확인 환경변수·별도 이미지 키로 전환하지 않는다. 로그의 key_slot은 원래 등록 번호를 유지한다. 무료 한도·모델 지원 오류가 모두 발생하면 중단하고 기록한다.
