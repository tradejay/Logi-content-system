# SYS-WEB-PLANNING-004 — 관련 글 우선 기획 탐색

2026-10-08 사용자 지정. AVIXA·PSNI 자료는 **기획 참고자료 탐색**에 우선 사용한다. 기존 SYS-WEB-EVIDENCE-002의 기획 전 근거 심사·미검증 대기 계약 대신 이 계약을 적용한다. 출처 허용 범위와 신뢰 점수는 SYS-WEB-SOURCE-TRUST-003을 유지한다.

## 실행 순서

주제·키워드 → AVIXA·PSNI 관련 글 탐색 → 기획 참고자료 선별 → 기존 제품 Fact 결합 → 블록 기획·집필 → 검토 → 로지텍 AI 제품 검증.

1. `related_articles`: 주제 관련 글이 있으면 문제 제기, 설명 흐름, 선택 기준, 사례·조건·한계·보완·대안을 기획에 참고한다. 원문 구성을 무조건 복제하지 않는다.
2. `fact_fallback`: 관련 글이 없으면 두 기관의 개별 사실·설계 원칙만 전달한다. 이를 관련 글을 발견한 것으로 기록하지 않는다.
3. `product_facts_only`: 관련 글과 개별 근거가 모두 없거나 탐색/선별이 실패하면 기존 제품 Fact로 계속한다. 웹 자료 없음만으로 NEEDS_EVIDENCE에 넣지 않는다. 제품 자체의 필수 근거 부족 게이트는 유지한다.

## 범위와 전달 계약

- 실제 도메인이 확인된 두 기관 자료는 신뢰 점수 1.0으로 자동 채택한다. 기관 자료의 신뢰성에 대한 별도 수동 승인은 요구하지 않는다.
- 검색 호출은 주제·주요 키워드만 전달한다. 선별 호출 `planning_research`도 검색 출처·인용 연결 문장만 받는다. 제품 사양 판정 역할을 맡기지 않는다.
- 기획·집필·피드백에는 `planning_references`를 별도 전달한다. 기존 제품 `facts` 배열에 기관 자료를 합치거나 제품 Fact ID를 생성하지 않는다.
- 관련 글은 `article_source_ids`, 참고 항목은 `segment_id`, `source_ids`, 실제 전달 문장, 용도(`use`), 기획 메모, 출처 URL을 보존한다. 최대 8개 항목만 전달한다. 출처 없는 항목은 제외한다.
- 선택한 참고 문장이 인용하지 않는 추가 글 ID는 `excluded_article_source_ids`에 기록하고 제외한다. 유효한 참고 문장은 유지하며, 검색 목록에 있다는 이유만으로 실제 참고한 글로 표시하지 않는다.
- 원문 전문을 수집하지 않은 grounding 요약은 `quote_origin=grounded_summary`로 기록한다. 직접 발췌나 원문 전체 검토로 표현하지 않는다.
- 모든 참고자료를 본문에 넣을 의무는 없다. 사용한 내용의 조건·한계를 보존한다. 브랜드에 불리한 내용도 중요한 판단 조건이면 기획에 반영하고, 보완/대안의 근거가 없으면 조사 과제로 구분한다. 누락된 정보는 추측으로 채우지 않는다.
- 기관 권고와 제조사 제품 사양은 구분한다. 로지텍 제품 수치·호환성은 기존 제품 Fact 및 로지텍 AI 검증 경로로 확인한다.

## 로그와 재개

전체 연결·출처·전달·검토 로그의 기계적 검사와 실행 종료 시 자동 보고서는 [SYS-PIPELINE-VERIFY-005](pipeline-mechanical-verification.md)를 따른다.

- `web-research.json`: 실제 검색 지시·검색어·출처·grounding 연결·사용량.
- `web-planning-discovery.json`: 세 가지 분기, 이유, 참고 항목, 출처. 선별 실패는 `status=failed` 및 관리자 항목으로 남긴다.
- `prompts/planning-research.*`, `responses/planning-research.*`, `rule-audit/planning-research.json`, 토큰 기록: 기존 실행별 규칙 전달/receipt 검증 계약을 사용한다. SYS-WEB-PLANNING-004와 SYS-WEB-SOURCE-TRUST-003을 기록한다.
- 재작성·검토 재개 시 저장된 선별 결과를 승계한다. 자동 검색 재시도는 하지 않는다.
- 기존 불변 활성 정책 릴리스는 수정하지 않는다. 이 계약은 실행 시 추가하는 버전 관리 코드·시스템 규칙으로 전달된다.
