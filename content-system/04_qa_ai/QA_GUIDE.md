# QA 가이드 v3

공통 검토 절차는 [재작성·로지텍 AI·대기열](../02_writer_ai/authoring/05-feedback-and-review.md), 완료 판정은 [콘솔·완료](../02_writer_ai/authoring/06-completion-and-console.md)를 따른다.

1. 같은 revision의 Brief/Context Pack/원고/Claim map/자산 binding을 입력받는다.
2. 기술 주장의 주체·속성·값·단위·범위와 실제 Fact/source를 대조한다. 미매칭은 미검증이다.
3. 선택된 주의사항 준수, 독자 질문 해결, 초반·중반·마감 흐름, 이미지 정합성을 확인한다.
4. 위치·규칙·근거가 있는 피드백을 내고 수정본에서 해결 여부를 다시 확인한다.
5. 로지텍 AI의 Claim별 판정과 근거를 확인한다. 응답 없음/파싱 실패는 오류다.
6. 원고 오류와 지식 변경 후보를 구분해 지식 대기열에, 관리자 판단 항목은 관리자 대기열에 적재한다.
7. 자동 작성 종료 결과와 사람 컨펌·발행 가능 여부를 따로 출력한다.

점수만으로 근거 누락·미승인을 상쇄하지 않는다. 필수 질문과 승인 기준은 글별 Strategy와 정책에서 가져온다. 기존 검사 스크립트의 80/85점 또는 문자열 일치 결과는 v3 계약 준수의 증명이 아니며 기존 구현의 한계는 코드 리뷰 보고서에 기록되어 있다.
