# RULE-NUMERIC-SCOPE — 수치·단위·측정 조건

Version: 1.0.0

제품/부품 + 속성 + 값 + 단위 + 적용 조건 전체가 근거와 일치해야 한다. 같은 숫자가 다른 Fact에 있다는 이유로 재사용하지 않는다. 최대와 권장, 반경과 직경, 수평과 대각선 화각, 수음과 카메라 동작 거리를 구분한다.

단위 변환은 계산과 원본 값을 추적 가능하게 남긴다. 정수 표기를 정리하는 것과 정밀도를 임의로 반올림하는 것은 다르다. 정의가 불분명한 수치를 선택적으로 해석해 원고에 쓰지 않는다.

검토 출력: numeric Claim별 주체·속성·값·단위·조건 대조 결과.
