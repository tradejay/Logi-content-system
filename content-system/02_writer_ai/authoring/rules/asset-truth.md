# RULE-ASSET-TRUTH — 이미지와 본문 정합성

Version: 1.2.0

그림의 숫자·라벨·기능 관계도 본문과 같은 근거 기준을 적용한다. 공식 자료, 자체 촬영, 생성 이미지를 구분하고 생성 이미지를 공식 스크린샷이나 실제 테스트 증거로 소개하지 않는다.

초안에서는 미확보·미승인 이미지도 `{{asset:NEED-ID}}`로 필요한 위치를 계획할 수 있다. 본문 편집 확정 후 문단에 맞는 공식 자료를 연결하거나 상황 사진·한글 설명 카드를 제작하고 검토한다. 최종 발행에는 선택한 AssetNeed에 연결된 승인 Asset ID/revision만 사용한다. 이미지 생성·업로드·URL 존재는 내용 승인과 다르다. 파일·사용 권한·외부 접근 URL·표시 문구를 확인한다. 필수 이미지 부재는 미해결로 보고하고 무관한 사진으로 채우지 않는다.

실제 제품 외형은 공식 제품 사진, 실제 기능 동작은 공식 GIF·영상으로 설명한다. 생성 사진은 본문과 관련된 일반적 환경·사용 상황으로 제한하고, 한글 설명 카드는 문단의 문제나 개념을 전달한다. 생성 이미지로 제품 성능·추적 정확도·지원 조건을 입증하지 않는다. 특정 장비의 오작동이나 개선 효과를 근거 없이 암시하는 전후 비교도 허용하지 않는다.

이미지 수를 섹션당 하나로 제한하지 않는다. 문단별 시각적 질문에 대응하는 자산을 연결하며, 역할이 다른 공식 사진·GIF·생성 카드는 같은 섹션에 배치할 수 있다. 실물과 동작 자료를 생성 사진으로 대체하거나, 무관한 사진으로 누락을 감추지 않는다. 텍스트가 포함된 카드는 한글 문구와 암시된 주장까지 검토하고 GIF는 실제 애니메이션 재생을 확인한다.

검토 출력: need ID, asset ID/revision, origin, rights, 승인자, Claim 및 URL 확인 결과.
