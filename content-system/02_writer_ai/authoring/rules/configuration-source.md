# RULE-CONFIGURATION-SOURCE — 메뉴와 배선

Version: 1.0.0

메뉴 경로·옵션·배선·호환 연결은 해당 제품/버전 공식 자료를 확인하고 쓴다. 경로 일부가 같다는 이유로 전체 경로를 검증 완료로 처리하지 않는다. 문서에 없는 내부 알고리즘이나 연결 구조를 그럴듯하게 채우지 않는다.

독자가 실행할 절차에는 전제 조건, 작업 순서, 정상 확인 방법, 확인된 제약을 포함한다. 자료가 부족하면 조사 항목으로 남기며 생성 UI 이미지로 공식 화면을 대체하지 않는다.

검토 출력: 작업 단계별 source locator와 미확인 단계.
