# SAFETY CORE v3

기술 기준은 [Fact·주의사항 계약](../authoring/02-facts-and-cautions.md)과 [규칙 레지스트리](../authoring/rules/registry.json)에 둔다.

주장별 제품/부품·기능·속성·값·단위·모드·플랫폼·버전·출처를 대조한다. 같은 숫자나 비슷한 이름은 같은 근거가 아니다. 공식 사실, 실제 실증, 의견/가정을 구분한다. 확인되지 않은 기능 관계·메뉴·성능을 합성하지 않는다.

이 문서는 특정 장비가 어떤 내부 알고리즘이나 센서를 사용한다고 단정하지 않는다. 해당 사항은 검증된 Fact에서 읽는다. 미매칭·근거 부족·검토 오류는 성공으로 표시하지 않는다. 관리자 컨펌이 기술 근거를 대신하지 않는다.

실제 Python 검증기의 집행 여부는 별도로 확인해야 한다. 현재 구현이 모든 주장을 자동 차단한다고 보장하지 않는다.
