# STYLE CORE v3

문체 상세 기준은 [초반·중반·마감](../authoring/03-opening-body-closing.md)과 [RULE-READER-STYLE](../authoring/rules/reader-and-style.md)이다.

친절한 경어체, 짧은 문단, 질문에 대한 직접적인 답을 기본으로 한다. 수치·용어는 판단에 필요한 만큼 쓰며 읽기 쉬운 표현으로 연결한다. 표와 목록은 비교·절차에 필요할 때 선택한다. 내부 채점 라벨과 ID는 본문에 넣지 않는다.

‘완벽한’을 ‘오차 없는’으로 바꾸거나 ‘업계 표준’을 ‘가장 널리 도입된’으로 바꿔 근거 없는 주장을 유지하지 않는다. 예문은 사실의 출처가 아니다. 문체 예시에 제품별 성능·거리·기능 관계를 끼워 넣지 않는다.
