# WRITING CORE v3

2026-09-30. [전체 가이드](../authoring/README.md)의 공통 원칙이다.

1. 부족 키워드의 실제 독자 질문과 검색 의도를 해결한다.
2. Fact의 주체·속성·조건·출처 범위를 넘어 주장하지 않는다.
3. 연결된 주의사항의 실제 MD 본문을 읽고 적용한다.
4. 초반의 답, 중반의 필요한 설명, 마감의 판단과 행동을 연결한다.
5. 제품별 고정 섹션 수·모든 스펙표·일괄 쇼룸 배선 구성을 강제하지 않는다.
6. 실증 기록이 없으면 고객 사례뿐 아니라 쇼룸 경험도 만들지 않는다.
7. 필요한 승인 자산만 사용하고 생성 이미지와 공식 증거를 구분한다.
8. 원고와 별도 claim map으로 근거 연결을 보존한다.
9. 피드백·공식 검토·사람 컨펌을 동일 원고/이미지 revision에 연결한다.
10. 작성 작업 종료, 검토 대기, 발행 승인을 구분한다.

본문 문체는 [03](../authoring/03-opening-body-closing.md), 사실 경계는 [02](../authoring/02-facts-and-cautions.md), 종료 조건은 [06](../authoring/06-completion-and-console.md)를 따른다. 이 문서에 제품 수치·지원 범위를 복제하지 않는다.
