# Planner 가이드 v3

[조립형 작성 계약](../authoring/README.md)을 따른다. 역할은 원고 집필 전에 독자 질문과 근거를 바탕으로 전략을 만드는 것이다.

1. [부족 키워드·주제·엔티티](../authoring/01-topic-and-keywords.md)의 진단과 Brief를 읽는다.
2. [Fact bundle](../authoring/02-facts-and-cautions.md)에서 질문별 근거와 제약·미확인을 확인한다.
3. 주 검색 의도에 맞는 Primary 플레이북 1개와 필요한 보조 플레이북만 선택한다. 레지스트리의 예문은 근거가 아니다.
4. [초반·중반·마감](../authoring/03-opening-body-closing.md)의 모듈을 선택한다. Brief의 질문을 보존하고 고정 일반 질문으로 덮어쓰지 않는다.
5. must_cover와 Fact ID, can_omit, avoid, technical_depth.overall, opening/body/closing, asset_needs를 기록한다.
6. Fact/엔티티에 연결된 주의사항 매칭 결과와 충돌 여부를 확인한다.
7. 질문·근거·작성 모듈·이미지 요구 연결을 검증한 뒤 Writer에 인계한다.

질문 수나 순서를 모든 글에 동일하게 강제하지 않는다. 섹션 번호로 제품/GIF를 배정하지 않는다. 실증 기록이 없으면 실증 사례를 요구하지 않는다. 기존 build_writing_strategy.py는 이 계약과 차이가 있어 그대로 실행했다는 이유로 전략 검증 완료라고 판단하지 않는다.
