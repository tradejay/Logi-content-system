# Configuration How-to Playbook (설정 작업형 글쓰기 가이드)

## 1. PURPOSE
장비를 도입한 현장 관리자나 실무자가 군더더기 없이 메뉴를 찾아가 원하는 기능을 활성화하고, 정상 작동 여부를 스스로 검증할 수 있도록 명확한 실무 매뉴얼을 제공합니다.

## 2. READER STATE
"새로 설치한 랠리바에서 화자 추적을 켜고 싶은데, 리모컨으로 해야 하나요 Zoom 관리자 사이트에서 해야 하나요?"

## 3. SUCCESS CONDITION
- 설정의 필요성과 기본값(왜 변경해야 하는지)을 1~2문장으로 먼저 밝힌다.
- 사전 요구 조건(소프트웨어 버전, 권한, 리모컨/컨트롤러)을 누락 없이 명시한다.
- 추정이나 가짜 메뉴가 아닌 **공식 검증된 메뉴 경로(`Settings > Camera > ...`)**만 기재한다.
- 설정 완료 후 "어떻게 테스트해야 정상 동작을 확인(Verification)할 수 있는지"를 안내한다.

## 4. TYPICAL QUESTIONS
- "이 설정을 켜면 이전 설정은 어떻게 되나요?"
- "기기 온스크린 메뉴와 줌 관리자 포털 중 어디서 설정하는 게 편한가요?"
- "설정했는데도 동작을 안 할 때 1차로 확인할 것은 무엇인가요?"

## 5. GOOD OPENING PATTERNS
- **⭕ 좋은 도입**: "로지텍 회의실 카메라를 처음 설치하면 기본 설정값이 전체 인원을 비추는 '그룹 뷰(Group View)'로 되어 있는 경우가 많습니다. 만약 발표자에게 집중하는 '화자 뷰(Speaker View)'를 활용하고 싶다면, 터치 컨트롤러나 관리자 화면에서 단 1분 만에 설정을 변경할 수 있습니다."
- **❌ 나쁜 도입**: "본 문서는 CollabOS 펌웨어 릴리즈 v1.10에 따른 관리자 파라미터 조작 지침입니다."

## 6. RECOMMENDED FLOW
1. **설정 목적 및 배경**: 기본값과 변경 필요성 안내
2. **사전 준비물**: Tap 컨트롤러, 리모컨, 관리자 계정 등
3. **단계별 설정 경로 (Step-by-Step)**:
   - 기기 직접 설정 경로: `메뉴 ➔ 하위메뉴 ➔ 옵션 선택`
   - 플랫폼 관리 콘솔 경로 (Zoom Rooms / Sync)
4. **옵션별 효과 안내**: 어떤 옵션을 골라야 하는지 권장 기준 제시
5. **동작 검증 (Verification Step)**: 두 사람이 번갈아 말해보는 테스트 요령
6. **실패 시 1차 점검 (Quick Check)**: 케이블, 마이크 음소거, 거리 확인

## 7. ASSET STRATEGY
- **SCREENSHOT**: 실제 온스크린 메뉴 화면 또는 관리자 포털 UI 캡처
- **PROVE**: Tap 터치 컨트롤러에서 카메라 모드를 터치하는 사진

## 8. DO NOT
- 공식 매뉴얼에 없는 추정 경로를 지어내지 않는다.
- 스크린샷이나 경로 없이 글자로만 "설정 메뉴에 가서 켜세요"처럼 무책임하게 쓰지 않는다.
